# SwarmIDE
SwarmIDE — это высокопроизводительная C++ среда для визуального проектирования   * и оркестрации мультиагентных систем. Проект является нативным, быстрым аналогом n8n,  * написанным с использованием ImGui и OpenGL для максимальной плавности интерфейса.

___

Данный репозиторий сейчас находиться в заморозке, так как главный программист сдаёт сессию.
